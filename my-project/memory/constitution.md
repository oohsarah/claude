## 핵심 원칙 (Core Principles)

### Principle 1: 신속 정확한 분석 (Fast & Accurate Analysis)

**선언**: 모든 예산 집행 현황 분석은 신속하고 정확하게 수행되어야 한다.

**세부 규칙**:
- 데이터 수집부터 분석 결과 도출까지 최소한의 지연 시간을 목표로 한다
- 분석 결과의 정확도는 검증 가능한 수치로 측정되어야 한다
- 오류 발생 시 즉시 감지하고 알림을 제공해야 한다
- 데이터 무결성 검증 절차를 반드시 포함해야 한다

**근거**: 예산 의사결정은 시의성이 중요하며, 부정확한 분석은 잘못된 재정 결정으로 이어질 수 있다.

### Principle 2: 예측 기반 의사결정 (Predictive Decision Making)

**선언**: 과거 데이터를 기반으로 미래 예산 소요를 예측하여 선제적 의사결정을 지원해야 한다.

**세부 규칙**:
- 예측 모델은 과거 집행 패턴과 추세를 반영해야 한다
- 예측 결과에는 신뢰 구간 또는 불확실성 지표를 포함해야 한다
- 시나리오 분석 기능을 제공하여 다양한 상황에 대비할 수 있어야 한다
- 예측 정확도를 주기적으로 검증하고 모델을 개선해야 한다

**근거**: 사후 대응보다 사전 예측을 통한 선제적 예산 관리가 조직의 재정 건전성을 높인다.

## 거버넌스 (Governance)

### 버전 관리 정책

- **MAJOR**: 핵심 원칙의 삭제 또는 근본적 변경
- **MINOR**: 새로운 원칙 추가 또는 기존 원칙의 중요한 확장
- **PATCH**: 문구 수정, 오타 교정, 비핵심적 명확화

### 수정 절차

1. 변경 필요성 문서화
2. 영향 받는 이해관계자 검토
3. 버전 번호 결정 및 수정일 갱신
4. 관련 템플릿 동기화 확인

### 준수 검토

- 모든 기능 스펙은 핵심 원칙 준수 여부를 명시해야 한다
- 구현 계획은 원칙 위반 가능성을 사전에 검토해야 한다
- 코드 리뷰 시 원칙 준수 여부를 체크리스트에 포함한다
